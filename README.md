# לומדים לקרוא שעון

אפליקציה ללימוד קריאת שעון בעברית לילדים בגילאי 5-6.

## איך להעלות ל-GitHub ולקבל קישור קבוע (בלי לדעת לתכנת)

1. **פתחו חשבון חינמי** בכתובת github.com (אם עדיין אין לכם).
2. בעמוד הראשי לחצו על הכפתור הירוק **New** (או **+** ואז **New repository**).
3. תנו לריפוזיטורי שם באנגלית, למשל `clock-app`, ודאו שהוא מסומן כ-**Public**, ואז לחצו **Create repository**.
4. בתוך הריפוזיטורי החדש לחצו על **Add file** ואז **Upload files**.
5. גררו לתוך החלון את הקבצים **index.html** ו-**parent-guide.html** (מהתיקייה הזו), ואז לחצו **Commit changes**.
6. עברו ללשונית **Settings** (בראש הדף), ואז בתפריט הצדדי ל-**Pages**.
7. תחת **Build and deployment > Source** בחרו **Deploy from a branch**, ותחת **Branch** בחרו `main` ותיקייה `/ (root)`, ואז **Save**.
8. חכו דקה-שתיים ורעננו את הדף. יופיע למעלה קישור בנוסח:
   `https://<שם-המשתמש-שלכם>.github.io/clock-app/`

זהו הקישור הקבוע לאפליקציה - אפשר לשלוח אותו בוואטסאפ, הוא יעבוד תמיד ולא תלוי בשיחה הזו.

מדריך ההורים יהיה זמין בכתובת:
`https://<שם-המשתמש-שלכם>.github.io/clock-app/parent-guide.html`

## עדכון בעתיד
כדי לעדכן את האפליקציה בהמשך: היכנסו לריפוזיטורי, לחצו על הקובץ הרלוונטי, לחצו על סמל העיפרון (Edit), הדביקו את התוכן החדש ולחצו Commit changes. השינוי יופיע באותו קישור תוך דקה-שתיים.
